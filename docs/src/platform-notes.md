# Platform notes

_Not written yet. Target: milestones M1, M4 and M5._

Support matrix (spec §3):

- Windows 10 1809+ and Windows 11, with WebView2 Evergreen or a Fixed Version runtime. x86_64 and aarch64.
- macOS 12+, WKWebView. Profile isolation by data-store identifier needs macOS 14+.
- Linux: GTK 3.24 with WebKit2GTK 4.1, or GTK 4 with WebKitGTK 6.0 (2.40+).
