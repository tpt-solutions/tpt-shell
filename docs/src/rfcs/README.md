# RFCs

Changes to the design, the public API or the contract are proposed as an RFC here before implementation.

An RFC is a Markdown file named `NNNN-short-title.md` with: summary, motivation, detailed design, alternatives, drawbacks, and open questions. Accepted RFCs are merged; the decision is recorded in the file's status line.
